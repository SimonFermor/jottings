Some notes on what I'd do if I was getting started in Web Development

## Day One

On the first day, I'd do the following:

1. Create a [GitHub](https://github.com/) account and install the GitHub [client app](https://github.com/apps/desktop)
2. Download and install [Visual Studio Code](https://code.visualstudio.com/download)
3. Create an account on [CloudFlare](https://dash.cloudflare.com/sign-up)
4. Become familiar with Markdown, install the VS Code [extension](https://marketplace.visualstudio.com/items?itemName=DavidAnson.vscode-markdownlint)
